# NvVirtualList Family Design Spec

Two separate public components: `NvVirtualListContainer` provides the scroll-element context; `NvVirtualList` renders a virtual-height canvas and its generated rows. Source: [list](./NvVirtualList.vue), [container](./NvVirtualListContainer.vue), [props/context](./virtual-list.shared.ts), [story](./virtual-list.stories.ts), [virtualizer hook](../../../hooks/useVirtualizer.ts).

## Component Axes And Contracts

| Component | Input / contract                                        | Default                   | Actual behavior                                                                                                                                                                |
| --------- | ------------------------------------------------------- | ------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| List      | `count: Number`                                         | `0`, also `required:true` | Final virtualizer count and canvas Vue key; non-negative integer is expected usage, not enforced by a component validator.                                                     |
| List      | `options: Partial<VirtualizerOptions<Element,Element>>` | Fresh `{}`                | Overrides defaults as described below; vendor API, not a finite visual variant set.                                                                                            |
| List      | Scoped default slot                                     | No fallback content       | Receives `{ ...item }` for each virtual item (including `index`, `key`, `size`, `start`, and vendor item fields). Row wrapper is generated by the list; consumer owns content. |
| List      | Exposed `scrollToIndex(...args)`                        | —                         | Schedules `virtualizer.value.scrollToIndex(...args)` with `setTimeout`; forwards arguments, but does not synchronously return the vendor method’s result.                      |
| Container | Props                                                   | None declared             | Plain `div` with a ref; caller supplies viewport styles/attributes.                                                                                                            |
| Container | Unscoped default slot                                   | No fallback content       | Renders arbitrary child content, normally the list. Provides its element ref under the shared Symbol context key.                                                              |

### Options Merge And Lifecycle

Defaults are `getScrollElement: () => context?.container.value`, `estimateSize: () => tokens.spacing[7]` (numeric **32**), `enableSmoothScroll:false`, `overscan:5`. `...props.options` follows these, so it can override them, including `getScrollElement`. Final `count: props.count` and the component’s `onChange` wrapper follow the spread and cannot be replaced by `options.count/onChange`. The wrapper emits `change` and then invokes `options.onChange(instance)` when present. The hook supplies `observeElementRect`, `observeElementOffset`, and `elementScroll` as `scrollToFn`, also overridable by the merged options.

| Event (list only) | Timing                           | Payload | Visual effect                                                               |
| ----------------- | -------------------------------- | ------- | --------------------------------------------------------------------------- |
| `visible`         | After mount, inside `setTimeout` | None    | No visibility CSS change; not a viewport-intersection notification.         |
| `hidden`          | `onBeforeUnmount`                | None    | Lifecycle notification, not a hidden style or exit animation.               |
| `change`          | Virtualizer `onChange`           | None    | Update notification; the separate `options.onChange` receives the instance. |

Container declares no custom emits or exposed methods. These events are **behavior**, not visual states. Mount timers are not cancelled in component source; no stronger ordering guarantee is documented. The hook triggers its shallow ref on virtualizer change and disposes the vendor cleanup with scope disposal.

## Size Specification / Generated Geometry

All `rem()` values use Polished’s default 16px conversion base. Pixel equivalents below assume a 16px document root; a different root scales rem geometry, not literal px geometry. No fixed container size is implied.

| Part               | Source geometry                                                                                              | Consequence                                                                                                                                                                                                  |
| ------------------ | ------------------------------------------------------------------------------------------------------------ | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| Container viewport | Plain `div`; no dimensions, overflow, or clipping CSS                                                        | Caller must supply a bounded scroll viewport when needed. Story uses `height:200px`, `overflowY:auto`, `marginRight:10px`; none is a component default.                                                      |
| List canvas        | `height: rem(virtualizer.getTotalSize())`; Tailwind `relative` class                                         | Total-height spacer; relative positioning depends on shared utility CSS being loaded. Width is not explicitly set to 100% on the canvas.                                                                     |
| Virtual row        | `position:absolute; top:0; left:0; width:100%; height:${item.size}px; transform:translateY(${item.start}px)` | Literal px row geometry; only currently virtualized items (including overscan) are rendered. Slot content is not automatically clipped.                                                                      |
| Default estimate   | Numeric `tokens.spacing[7] = 32`                                                                             | Default virtual row estimate is 32px; the template does not attach `measureElement`, so content height alone does not automatically measure and resize rows. Custom options determine other sizing behavior. |

For default sizing and no custom offsets/padding/gaps, `getTotalSize()` is count × 32; canvas CSS is `(total / 16)rem`. At a 16px root this matches numeric vendor pixel geometry. At another root size the **canvas scales but row px heights and translations do not**, so the values must not be documented as uniformly rem-based. Zero count produces no row slots and default total size zero. Canvas key is `count`; each row is keyed `${item.index}-${item.key}`.

## Variant And State Styles / Token Mapping

There are no light/dark-specific colors, font rules, borders, radii, shadows, opacity, transitions, or interactive visual states in this family. Text can inherit; arbitrary row content styles itself. The sole direct token is the numeric estimate `tokens.spacing.7 = 32`, not a guaranteed row-content height.

Although vendor options can include horizontal virtualization, this template always applies height and `translateY`, never width and `translateX`. Do not present horizontal scrolling as an implemented visual orientation variant merely because the options type accepts it.

## Structure / Figma Handoff

Keep the provider viewport, internal total-height canvas, absolute row wrappers, and consumer row content distinct. Use a representative vertical list inside the consuming feature’s scroll frame. Enable clipping in Figma only if the caller actually supplies clipping/overflow. Annotate estimated height, overscan, and lifecycle separately; do **not** create `visible/hidden/change`, Theme, Container/List, or Has Provider visual variant axes. The two exports are structural roles, not alternate appearances of one component.

## Context / Remaining Uncertainties

- With no provider and no custom `getScrollElement`, optional chaining returns `undefined`; the TypeScript cast does not turn it into null. No fallback viewport, local error handling, or missing-provider appearance is implemented. Vendor response should not be guessed as a designed state.
- Consumer options and viewport CSS determine final range, offsets, measured/cache sizes, total scroll size, and clipping. Full options are the pinned TanStack API rather than a component-specific visual matrix.
- Browser/feature integration must supply utility CSS and sensible container bounds. This spec does not claim a full app virtualization test.
