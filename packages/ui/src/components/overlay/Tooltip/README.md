## Scope Prerequisite — Read Before Reconstructing

`StTooltip` is an empty styled `div`. The theme rules are inside `GlobalStyles = styled('div')`, **not `injectGlobal`**. Its generated class prefixes the nested `[data-theme="tooltip"]` and `[data-animation]` selectors; these affect matching descendants of that DOM wrapper. ThemeProvider alone does not create those selectors or DOM ancestry.

NvTooltip defaults `appendTo` to the injected `PORTAL_TARGET` resolved by `getElement`, otherwise `document.body`. A body-portalled bubble outside GlobalStyles is **out of scope**, even if the trigger is inside GlobalStyles. A portal inside that wrapper can match. Storybook's inspected decorator provides only ThemeProvider, so the local source does not establish the themed bubble there. No exact out-of-scope computed bubble appearance is asserted; applicable vendor/caller CSS determines it.

## Size Specification — Conditional Themed Surface

The themed box padding, shape and typography conditions below apply **only when GlobalStyles contains the matching portalled surface** and options retain `theme: 'tooltip'`. Default renderer structure and option `maxWidth: 300` do not require that CSS scope; caller overrides can change them.

| Part                               | Dimensions                                                                                                                  | Padding                                               | Shape / effect                                                                                      | Typography                                                                |
| ---------------------------------- | --------------------------------------------------------------------------------------------------------------------------- | ----------------------------------------------------- | --------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------- |
| Tippy box `[data-theme="tooltip"]` | Local option `maxWidth: 300`; height content-driven; no min-width or fixed width/height                                     | `spacing.1 spacing.2` = `2px 4px` **on selected box** | `borderRadius.xs=4px`; `borderWidth.DEFAULT=1px`; `boxShadow.lg`                                    | No family, size, weight, line-height or letter-spacing set by bubble rule |
| Descendant content                 | Default `.tippy-content` div containing a vue-tippy `span`; inner span display is `none` before mount, `inherit` afterwards | No `.tippy-content` padding override here             | No local icon/divider dimensions; default arrow is a `.tippy-arrow` div with CSS-dependent geometry | Every descendant receives `color: inherit !important` in this scope       |
| Reference wrapper                  | Default `span[data-v-tippy]`; receives inline-flex only in GlobalStyles scope                                               | No local padding                                      | `StTooltip` itself is empty                                                                         | Trigger child-defined                                                     |

The 2px/4px declaration is not a verified total text inset: nested vendor/caller content padding may contribute. Border **style** is not declared here; border-width/color alone do not guarantee a visible stroke. Token `rem()` equivalents assume 16px root: padding .125rem/.25rem, radius .25rem. No clipping or fixed icon size is defined locally. Do not assert an unconditional 4px-radius bordered bubble outside the prerequisite.

## Interaction And Motion

| Concern            | Effective default contract (caller-overridable)                                                                                                                                                                                                                                                                                                                                                                                                                                                                                              |
| ------------------ | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Trigger            | `mouseenter focus`                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                           |
| Delay              | **`[250, 0]`**: show waits **250ms**, hide has **0ms pre-hide delay**. This is separate from transition duration.                                                                                                                                                                                                                                                                                                                                                                                                                            |
| Interactivity      | `interactive: false`; override possible via `tippyOptions`, but no alternate local interaction skin.                                                                                                                                                                                                                                                                                                                                                                                                                                         |
| Placement / offset | `top`, `[0, spacing.4] = [0, 12]`; max width 300.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                            |
| Portal / theme     | Injected target or `document.body`; `theme: 'tooltip'`. Options may override either and invalidate the scope/theme match.                                                                                                                                                                                                                                                                                                                                                                                                                    |
| Suppression        | `useFocusWithin(tooltip)` watcher calls instance `disable()` on true, `enable()` on false, if stored instance has that method. No immediate watcher option is supplied. Consequently focus trigger is configured, but focus-within logic may suppress it; exact sequencing is not browser-verified.                                                                                                                                                                                                                                          |
| Inherited options  | `animation: 'fade'`, `duration: [300, 250]` (show/hide ms), `arrow: true`, `role: 'tooltip'`, `zIndex: 9999` from pinned Tippy via vue-tippy. Default renderer writes normal inline transitionDuration on box/content as visibility changes; these are option values, not proof of a visible CSS fade.                                                                                                                                                                                                                                       |
| Conditional fade   | GlobalStyles descendants carrying `[data-animation]` get `tokens.transition.DEFAULT = 'all .3s' !important` and hidden/visible opacity 0/1. **300ms CSS transition**, only in matching scope; its important shorthand overrides Tippy's normal inline duration on the matching box (including the 250ms hide value). It does not target `.tippy-content` unless that element itself has data-animation. Visible timing/complete fade still depends on applicable CSS and Tippy lifecycle; out-of-scope portals have no local fade guarantee. |

The local code does not set `duration`, `animation`, `arrow` or `role`, so the pinned defaults above apply unless caller options or configured vendor defaults override them. Arrow existence is source-resolvable, but arrow dimensions and visible styling require applicable CSS. Local UI styles do not import `tippy.css`; its content insets, text metrics and arrow geometry are not unconditional component values. No local keyboard-dismissal customization is supplied. The UI shared `.v-*` Vue fade is a different mechanism; NvTooltip contains no Vue Transition wrapper.

## Figma Build Notes

- Label the specimen “GlobalStyles-scoped tooltip”; do not present its color/radius/stroke as generic NvTooltip output.
- Keep default reference span and popper wrapper nonvisual; preserve box → content div → content span nesting. Add scoped box padding at the selected layer without assuming vendor content inset is zero. Include the default arrow as a separate layer, but choose geometry only from applicable stylesheet evidence.
- Assign explicit child typography when needed, not a guessed font/weight. Annotate inherited 300/250ms durations separately from 250/0ms delays; use the scoped 300ms box rule only for the scoped specimen, not an unconditional vendor fade. Keep a separate out-of-scope evidence gap rather than synthesizing browser values.

## Gaps / Assumptions

- Default wrappers, arrow presence, role and option durations are established by pinned vendor source. Exact out-of-scope surface, border-style, arrow geometry, total copy inset and visible motion remain dependent on caller/vendor CSS, options and portal scope; no browser values are substituted.
- Focus suppression sequencing and actual generated portal ancestry were not browser-tested; source contract and conditional scope are documented, not measured.
- Story's `content` control is not a component prop; default slot renders body. No runtime fixes are made here.
