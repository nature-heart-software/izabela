## Component Axes

| Property          | Kind        | Values                       | Default   | Notes                                                                                   |
| ----------------- | ----------- | ---------------------------- | --------- | --------------------------------------------------------------------------------------- |
| `open`            | Boolean     | True / false / undefined     | Undefined | Undefined means uncontrolled, initially local false; explicit Boolean means controlled. |
| `portalTarget`    | String      | Vue Teleport target selector | `'body'`  | Runtime prop is String, not a locally declared HTMLElement prop.                        |
| `reference`       | Named slot  | Trigger content              | Empty     | Rendered within `StDialogTrigger`; appearance is consumer-owned.                        |
| `title`           | Named slot  | Heading content              | Empty     | Title row and close affordance remain structurally present even if empty.               |
| `description`     | Named slot  | Supporting copy              | Absent    | Only rendered when `$slots.description` exists; wrapped in default NvText.              |
| `footer`          | Named slot  | Consumer content             | Absent    | After description within same Stack; no fixed footer layout, action count or copy.      |
| Default body slot | Unsupported | —                            | —         | No default slot invocation exists.                                                      |

`Props` type intersects `DialogRootProps`, but runtime declarations in this wrapper are only `portalTarget` and `open`; do not claim every inherited Ark prop is explicitly declared/forwarded. Possible Vue attribute fallthrough is distinct from an explicit wrapper API. The only declared wrapper emit is **`update:open`**, sent in controlled mode; uncontrolled changes update local state instead of emitting that wrapper event. Ark's internal open/dismiss events are not additional declared NvDialog emits.

Backdrop alpha 0.95 is in the fill, **not** an element opacity rule. Panel shadow `boxShadow.DEFAULT = 0 0.125rem 0.063rem rgba(0, 0, 0, 0.05)` has no specified spread. Button uses `transition.DEFAULT = all .3s`, distinct from shared Vue presence fade. Border-style for Button is not explicitly set by its local styled rules; reset/vendor styles are a prerequisite for a solid stroke. No shell hover, active, selected, loading or disabled variant is implemented. Dialog always supplies close Button with no selected/loading/disabled override; do not export those as dialog axes.

## Structure / Anatomy

| Part                  | Source                                                                      | Role                                                                                                                                                                |
| --------------------- | --------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Root / trigger        | Styled Ark Root / Trigger, `reference`                                      | Behavioral state and trigger; no root skin.                                                                                                                         |
| Teleport              | `props.portalTarget`, `defer`                                               | Default body target; rendering context is important for absolute cover layers.                                                                                      |
| Backdrop / positioner | Two unnamed Transition wrappers                                             | Separate scrim (`v-if`) and positioning (`v-show`) layers at z-index 9999; positioner transition classes do not override Content hidden flags.                      |
| Content wrapper       | Styled **Ark Dialog.Content**                                               | Retained Ark Content by default; hidden when closed, grid only without hidden. Semantic/focus-managed scroll area; local `@mousedown.self` closes on empty wrapper. |
| Inner shell           | Styled ordinary div                                                         | 480px width cap; not another Ark Content.                                                                                                                           |
| Card / Stack / header | Nested NvCard, NvStack, NvGroup                                             | Owns actual panel fill, content inset and spacing.                                                                                                                  |
| Title / description   | Ark Title asChild + NvText title; conditional Ark Description + NvText body | Semantic content + resolved text style.                                                                                                                             |
| Close / footer        | Ark CloseTrigger + plain squared Button; footer slot                        | Built-in dismiss affordance plus arbitrary consumer content.                                                                                                        |

Baseline script `provide(PORTAL_TARGET, portalTarget)` occurs at NvDialog setup scope, with ref attached to the Content wrapper. Descendant components resolving that injection can portal inside the dialog wrapper; unresolved target consumers fall back according to their own source. Do not assume every descendant portal has identical DOM ancestry.

## Interaction And Motion

| Concern                    | Current source contract                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                           |
| -------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Controlled / uncontrolled  | Getter uses props.open when defined, otherwise localOpen. Setter emits `update:open` only in controlled mode; consumer must update its prop.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                      |
| Local outside-card dismiss | **`@mousedown.self`**, not release click: checks target === currentTarget, then sets dialogOpen false. It is independent of vendor close-on-outside flags.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                        |
| Built-in close             | Ark CloseTrigger wraps the persistent plain `times` Button. Footer content has no automatic dismissal handler; story Cancel/Confirm buttons have no close wiring.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                 |
| Inherited defaults         | Pinned Zag: role dialog; **modal=true, trapFocus=true, preventScroll=true, closeOnInteractOutside=true, closeOnEscape=true, restoreFocus=true** unless vendor context overrides them.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                             |
| Focus / modality           | Modal trap activates when content exists; optional initialFocusEl can guide it, fallback is content. Focus returns on trap deactivation by default (optional finalFocusEl supported). Modal content outside is aria-hidden and body scrolling prevented. No bespoke local initial-focus target is set.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                            |
| Presence                   | Baseline backdrop **v-if**; positioner **v-show**. Default Ark render strategy is **lazyMount=false, unmountOnExit=false**: positioner and Content/panel subtree remain mounted even while closed. Zag Content supplies `hidden: !open`; Ark merges presence `hidden: !present`. With no local exit CSS animation, closed Content is retained but hidden independently of the positioner's Vue leave classes. Closed positioner also has pointer-events none. Explicit caller render-strategy/CSS overrides can alter this default contract.                                                                                                                                                                                                                                                      |
| Shared fade                | Unnamed Transitions use `.v-enter-active/.v-leave-active { transition: all 0.3s }`, `.v-enter-from/.v-leave-to { opacity:0 }` in imported `styles/main.scss`. Both backdrop and positioner receive shared **300ms transition classes**; after leave, v-show hides the retained positioner rather than removing it. This is not a guarantee of a visible 300ms panel leave fade: Ark hides Content independently, and pinned presence tracks CSS animation names/events, not this transition. Backdrop has a separate `v-if` leave wrapper; its unmount lifecycle must not be equated with the retained Content/positioner contract. No local exit CSS animation is declared. Hard-coded shared 300ms, not `tokens.motion` consumption; visible output depends on applicable CSS/caller overrides. |

Pinned Ark `use-dialog.js` connects its open changes to `update:open`; the wrapper binds that event. Machine outside/escape dismissal and focus defaults are verified source behavior, not browser measurements; no claim is made about exact first focused child in arbitrary footer/trigger content or about capture-event ordering.

## Merge Compatibility Note — Separate Dev/Nx Truth, No Merge Performed

Read-only inspection of `origin/dev` at **`ae580ccc176d78eb26e0c3ccd4bd5bf0df6d12f4`** shows `NvDialog.vue` using **`v-if="dialogOpen"` on the positioner**, and a **`PortalTargetProvider`** around the teleported subtree which provides `PORTAL_TARGET`. It removes the baseline setup-level provide and scopes provision to that provider. This changes wrapper lifetime and injection scope compared with this document's baseline **v-show + setup-level provide**. For a later merged/dev-target handoff, recheck presence/lifecycle and nested portals; do not silently rewrite the baseline claim. No checkout, merge or app fix was performed for this documentation update.

## Figma Build Notes

- Build an outer centered scroll frame with 8px clearance, then width-fill shell capped at 480px and Card with 16px inset, 8px corners, no Card stroke.
- Use vertical 16px gaps, 8px header gap and space-between title/close placement. Close is 16px square with a 12px glyph; do not use default 24px Icon size.
- Backdrop fill alpha is separate from Vue opacity transition classes. Export open and hidden/closed states; do not promise a visible 300ms panel leave fade from the positioner wrapper alone. Keep the retained Content hidden in the default closed specimen, with v-show hiding its outer positioner after leave. Keep trigger and behavior-only layers outside the panel component; retain footer as arbitrary content.

## Gaps / Assumptions

- Default retained/hidden behavior is source-resolved, not an unspecified presence gap. Actual cover extent under custom Teleport targets, caller override effects, visible motion and exact focus/event ordering require runtime verification; no arbitrary footer sizing or typography is guessed.
- No default body slot or optional close-button switch exists. Header's `between` type/style-map mismatch is recorded, not repaired.
- Current truth remains v-show; dev/Nx compatibility is a distinct note. No runtime modifications or merges belong to this task.
