# NvTable / NvTableColumn Design Spec

Purpose: attribute/listener and scoped-slot forwarding wrappers around Element Plus `ElTable` and `ElTableColumn`. There is no local styled shell, theme map, size system, pagination, loading prop, or disabled-table mode. The public visual contract below is the **pinned Element Plus 1.2.0-beta.6** contract, not the current upstream API.

Selection/index/expand force `sortable: false`; selection and expand force `resizable: false`. These overrides apply even if conflicting props are supplied. Columns have no independent visible wrapper frame. Both local wrappers forward every supplied slot with vendor scope (or `{}` if no scope); table consumes `default`, `empty`, `append`, and columns consume `default`/`header`. Forwarding an arbitrary slot name does not make it a new vendor-rendered content region.

The effective header renderer follows the full setup chain: `table-column/index.mjs:83–86` composes forced props → widths → renderers (right-to-left `util.mjs:174–181`). Although `config.mjs:64–67` initially supplies an index `#` fallback, `table-column/render-helper.mjs:65–74` overwrites it when `renderHeader` is absent, returning the header slot or `column.label`. With neither label nor header slot, an index header therefore renders no text. Do not recreate the intermediate fallback in Figma; selection retains its forced checkbox header.

Default summary puts `sumText || locale sumText` in the first column, converts remaining column values with `Number`, sums numeric values (ignoring NaN), and renders empty string for an entirely nonnumeric column; `summaryMethod({ columns, data })` replaces the result. `emptyText || locale emptyText` supplies empty copy unless the empty slot exists, so an empty prop string does not suppress the locale fallback. For overflow poppers, pinned `util.mjs:237–245` assigns the cell's `innerText || textContent` string to popper `innerHTML`; preserve this implementation detail rather than promising a sanitized/custom NvTooltip rendering path.

## Size Specification / Typography

| Resolved size           | Root text size | Cell padding Y / inner padding X | Inner line-height | Radius / separator                   |
| ----------------------- | -------------- | -------------------------------- | ----------------- | ------------------------------------ |
| Base (no size modifier) | 14px           | 12px / 10px                      | 23px              | No radius rule / 1px solid separator |
| `medium`                | 14px           | 10px / 10px                      | 23px              | Same                                 |
| `small`                 | 12px           | 8px / 10px                       | 23px              | Same                                 |
| `mini`                  | 12px           | 6px / 10px                       | 23px              | Same                                 |

No fixed row height, root min-height, ordinary root min-width, or gap is set. Single-line text row height follows content line-box + vertical padding + border; wrapping, spans, custom slots, tree prefixes and checkbox wrappers can increase it. Selection cells ordinarily use **14px left / 14px right inner padding** (`element-plus/theme-chalk/src/table-column.scss:6–11`). In border mode, including grouped headers (`table.vue_vue_type_template_id_4a1660ad_lang.mjs:55–59`), the more specific `.el-table--border .el-table__cell:first-child .cell` rule overrides left padding to **10px**, leaving right padding **14px** for a first selection cell in each rendered row/header (`element-plus/theme-chalk/src/table.scss:272–287`). These values assume no consumer overrides. Expand cells use zero inner padding and centered text, except that the same border-mode first-cell rule sets their left padding to 10px too.

Table CSS does **not** set font-family, body font-weight, letter-spacing, text-transform or decoration. With this package's global Tailwind preflight and `tailwind.config.cjs`, the default family is `Nunito, system-ui, -apple-system, BlinkMacSystemFont, "Segoe UI", Roboto, "Helvetica Neue", Arial, "Noto Sans", sans-serif, "Apple Color Emoji", "Segoe UI Emoji", "Segoe UI Symbol", "Noto Color Emoji"`; parent font styling can replace it. Unmodified CSS defaults give normal weight/letter-spacing, no transform/decoration, but these are inherited context, not Nv theme tokens or forced Table styles. Root line-height comes from context (global preflight 1.5 absent override); `.cell` always declares 23px and empty text 60px. Do not substitute the NvText 14px/1.4/.32px style for vendor cells.

### Selection checkbox detail

Selection column header shows all/partial selection; empty-data header is disabled. Row `selectable` can disable a checkbox; checkbox click stops propagation rather than making the row current. Checkbox selection does not itself add a row fill. Vendor unbordered checkbox outer heights are base 40px, medium 36px, small 32px, mini 28px; **inner box stays 14×14px** (12px small/mini inner rules apply only to bordered checkboxes, which Table does not request). Selection rows therefore need not match text-only row height.

| Checkbox state             | Fill / border / mark (vendor variable context)                                                                                    |
| -------------------------- | --------------------------------------------------------------------------------------------------------------------------------- |
| Rest                       | `--el-checkbox-bg-color` → white; `--el-checkbox-input-border` → 1px solid #dcdfe6; radius `--el-border-radius-small` → 2px       |
| Hover / focus              | Border `--el-checkbox-input-border-color-hover` → primary #409eff; focus changes border, not a separate ring                      |
| Checked / indeterminate    | `--el-checkbox-checked-bg-color` and checked border → #409eff; mark `--el-checkbox-checked-icon-color` → `--el-fill-base` → white |
| Disabled unchecked         | Fill #edf2fc; border #dcdfe6; cursor not-allowed                                                                                  |
| Disabled checked / partial | Fill `--el-border-color-extra-light` → #f2f6fc; border #dcdfe6; check/partial mark #c0c4cc                                        |

Checkmark is a 3×7px content-box L-shaped 1px stroke at left 4px/top 1px, rotated 45°; partial mark height 2px, left/right 0, top 5px, scale(.5). Inner fill/border transition .25s `cubic-bezier(.71,-.46,.29,1.46)`; check transform .15s ease-in with .05s delay. Hidden native checkbox remains the interaction control; selection semantics come from vendor checkbox, not a blanket Table disabled state.

## Recommended Figma Mapping / Figma Build Notes

Use nested columns/cells, not a separate visual `NvTableColumn` wrapper. Expose Density (base/medium/small/mini), Stripe, Border, Header, Summary, Current-row-highlight, Column Type, Alignment, Frozen side, Sort order, Selection state, Expanded/tree state and Overflow tooltip where used. Preserve hover/current/stripe precedence and special-type forced overrides. Make header/body/footer synchronized regions and frozen panes overlays with conditional edge shadows. Keep `empty`, cell/header/expanded/append content replaceable; do not assign arbitrary slot typography. Represent CSS-variable context as annotations/shared styles; do not invent an Nv light/dark Table axis. Story widths and fixed-right choice are examples, not defaults.

- Header content must match the effective renderer: an unlabeled index column without a header slot has no `#` text fallback.
- Selection `.cell` padding is 14px on both sides ordinarily; a first selection cell in border/grouped-header mode is 10px left / 14px right. Keep this conditional override separate from density and checkbox dimensions; the border-mode first-cell left override also applies to other column types.
- Overflow-tooltip open state is driven by child nodes and measured range/scroll overflow, not a nonempty text value. Allow an empty popper for overflowing non-text content; do not promise one for every visually clipped slot.

## Gaps / Assumptions

- No browser-computed dimensions or content-specific row heights were measured. Actual widths, scrollbar/gutter allocation, pane heights, text wrapping, custom spans and inherited font metrics depend on host/data/slots. Gutter CSS fallback is 15px (body gutter width 0), while runtime layout measures scrollbar width.
- Changing `as` is not a Table prop. Attrs/listeners pass through; wrapper refs do not explicitly expose the vendor instance's imperative methods.
- Locale supplies default empty/summary copy. Filtering choices, custom CSS variables, callbacks, slots and row/cell styles are consumer context; their arbitrary content cannot be assigned a fixed visual value here.
- Imported vendor defaults are not conditional on Nv `themes.light`/`themes.dark`; application CSS may override them independently. The 1.2.0-beta.6 API includes legacy aliases and densities; do not replace it with a newer Element Plus spec.
