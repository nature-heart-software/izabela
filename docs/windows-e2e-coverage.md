# Windows macro journey coverage

This maps the supplied Izabela Windows E2E checklist (44 macro journeys) to executable app cases. It describes coverage, not an execution result. Run results are in `coverage/app-results/*/summary.json`.

Tests launch real production bundles or the shipped ASAR, with disposable settings/cache and muted analysed playback. Native shortcuts and a foreground window exercise Windows hooks. Microphone audio comes from the known WAV. Cloud cases require Infisical dev; unconfigured providers are reported, not passed.

A boundary means the macro journey remains Partial even when its automated cases pass. Entries without cases remain Manual. Installer replacement, UAC/startup registration, virtual-cable drivers, physical device switching, game injection, and subjective speech quality require a separate Windows setup.
